# Working conventions for this repo

## Git

- After completing a task or feature (not after every individual file
  edit), commit the changes and push to `origin main` on GitHub
  without asking for confirmation first.
- Still use judgment: don't push code known to be broken/half-finished,
  and don't push if the user has indicated more changes are coming as
  part of the same piece of work.
- Never force-push, rewrite history, or push to a branch other than
  `main` without explicit confirmation.
- Write commit messages that explain *why*, not just *what*, per normal
  commit message conventions.
